# ✨ GlassNotes — Premium Note-Taking Experience

GlassNotes is a modern, high-performance note-taking application built with **React Native** and **Expo**. It features a stunning **Glassmorphism UI**, seamless dark mode transitions, and a robust state management system to keep your thoughts organized in style.

---

## 🚀 Key Features

- 💎 **Glassmorphism UI**: Beautifully frosted note cards using `expo-glass-effect`.
- 🌓 **Dynamic Theming**: Smooth toggle between Light and Dark modes with system-aware defaults.
- 🔍 **Real-time Search**: Instant filtering by title, content, or category tags.
- 📌 **Note Pinning**: Keep your most important thoughts at the very top.
- 🏷️ **Categorization**: Organize notes into *Personal*, *Work*, and *Learning* with color-coded tags.
- 📊 **Writing Stats**: Live word count, character count, and estimated reading time.
- 📱 **Responsive Design**: Optimized layouts for both phones and tablets (multi-column support).
- 💾 **Persistent Storage**: Robust global state using React Context API.

---

## 📦 Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/Sameer-ts-tech/Notes-App.git
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npx expo start
   ```
